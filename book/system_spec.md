# 古書とからくり箱の謎 - 全体システム仕様書

熟練のゲームデザイナーおよびプログラマーの視点からまとめられた、本作の全体システム設計書です。

## 1. 概要
- **タイトル**: 古書とからくり箱の謎 (The Alchemist's Minimal Mechanical Chest)
- **構成**: プレイヤーは「解読手帳」に記されたヒントをもとに、からくり箱に施された5つの機械的試練を調律（クリア）し、古代のチェストを開放します。
- **世界観**: 錬金術や魔導、古代機械。

## 2. コア・ゲームフロー
1. **プロローグ / 手帳の閲覧 (導入)**
   - 起動直後は「からくり箱にようこそ」の演出画面。
   - プレイヤーは解読手帳を読み解きながら、開始ボタンまたはタブクリックでパズルを開始。
2. **5つの試練 (パズルフェーズ)**
   - 順番不問。プレイヤーは任意の順番でパズルを選択してプレイ可能。
   - 各パズル（第1〜5章）が解かれると対応する刻印が「調和（緑）」状態に変わる。
3. **調律完了 (エピローグ / エンディング)**
   - すべてのパズルが調律されると、ワープエフェクト演出が走り、最終リザルトモーダル（開放成功）が表示される。

## 3. 保存・ロード & ステート設計
- **永続化データ (LocalStorage)**:
  - `karakuri_solved`: 各試練のクリア状況をブール配列で保存（例: `[true, false, false, false, false]`）。
  - `karakuri_stage`: 最後に選択していた進行中のステージインデックスを保存。
  - `karakuri_hints`: 使用したヒント回数の保存。
- **セッションデータ (インメモリ)**:
  - `startTime` / `timeElapsed`: ゲーム経過時間をリアルタイム計算（完了時はタイマー停止）。
  - `showWinModal`: 全調律時のマスター完了画面表示トリガー。

## 4. 進行度とランク評価 (Alchemist Rank)
クリア時間（秒）とクリアしたステージ数により、プレイヤーに錬金術師としてのランクが授与されます。
- **学徒**: いずれかのパズルが未クリアの場合
- **古代神聖魔導師 (Divine Archmage)**: 全パズルクリア ＆ 240秒（4分）未満
- **宮廷高位錬金術師 (Palace Alchemist)**: 全パズルクリア ＆ 600秒（10分）未満
- **真理の研究者 (Truth seeker)**: 全パズルクリア ＆ 10分以上

## 5. 音響システム (Web Audio Synthesizer)
本作用に設計された内製の `AudioEngine` により、シンセ音をプログラム再生。
- クリック音（Tick）
- ギミック動作音（Slide/Rotate）
- 完全開放時（Success Fanfare）
- 刻印ロック解除（Unlock）
